# Micélio

Um jogo idle sobre uma colônia de fungos que cresce sob a floresta.

Toque no solo para absorver nutrientes, cultive 10 espécies reais de fungos, desça pelos horizontes do solo (O, A, B, C e R) e esporule para recomeçar mais forte.

**Jogar:** abra o `index.html` no navegador ou acesse a versão publicada no GitHub Pages.

- Salvamento automático no navegador a cada 10 segundos
- Progresso enquanto você está fora (até 12 horas)
- Funciona no celular
